Welcome

Welcome to UrbanNest, a modern real estate website template. This page provides basic installation instructions and technical support information.

Installation

  1. Download and extract the template ZIP file.
  2. Keep the HTML files and asset folders together.
  3. Open index.html in your browser to preview the website.
  4. Edit the HTML, CSS, and JavaScript files as needed.

Frequently Asked Questions

Can I customize the colors?

Yes. Update the CSS variables in the stylesheet.

Can I replace the images?

Yes. Replace them with images you have permission to use.

The layout does not display correctly. What should I do?

Check that the CSS, JavaScript, and image paths are correct.

Technical Support

For assistance, use the support contact provided by the seller or marketplace where you purchased the template.

Please include a description of the issue, the page affected, and the browser you are using.
